> 版本：v1.0  
> 日期：2026-03-04  
> 作者：Cascade AI  
> 状态：草稿

---

## 1. 项目概况

| 项目 | 详情 |
|------|------|
| **项目名称** | PandaMart PMS — 熊猫超市智能库存管理系统 |
| **预计总工期** | 12 周（约 3 个月） |
| **开发模式** | 敏捷迭代，每 1-2 周一个 Sprint |
| **技术栈** | React + TypeScript + Vite（前端）/ Node.js + Express + MariaDB（后端） |
| **部署环境** | Namecheap 共享主机 |

## 5. 风险管理

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|----------|
| Namecheap 共享主机 Node.js 运行限制 | 中 | 高 | 提前在 Phase 1 验证 Node.js 可运行性；备选方案：升级 VPS |
| AI OCR 识别准确率不够 | 中 | 中 | 持续优化提示词；积累模板库减少 AI 依赖 |
| 发票格式差异太大 | 中 | 中 | AI 方案天然适应多格式；人工校对作为兜底 |
| 开发工期延误 | 中 | 中 | P1 功能可推迟到后续版本；核心 P0 功能优先保证 |
| 共享主机性能瓶颈 | 低 | 高 | 缓存策略 + 异步处理 + 限流；终极方案升级 VPS |
| AI API 费用超预期 | 低 | 低 | 模板记忆减少 AI 调用；PDF 文本提取优先（免费）；支持切换到低成本提供商 |
| AI 提供商服务不可用 | 低 | 中 | 多提供商配置可快速切换；本地部署模型作为备份 |

## 6. 开发约定

### 6.1 代码规范
- **语言**：TypeScript（严格模式）
- **代码风格**：ESLint + Prettier
- **命名规范**：
  - 变量/函数：camelCase
  - 类型/接口：PascalCase
  - 数据库字段：snake_case
  - API URL：kebab-case
  - 常量：UPPER_SNAKE_CASE

### 6.2 Git 规范
- **主分支**：main（生产）、develop（开发）
- **功能分支**：feature/{功能名}
- **提交信息格式**：
  - `feat: 新增发票上传功能`
  - `fix: 修复库存计算错误`
  - `docs: 更新 API 文档`
  - `refactor: 重构 OCR 服务`
  - `style: 调整登录页布局`
  - `chore: 升级依赖版本`

### 6.3 目录结构约定
```
PandaMartPMS/
├── docs/                   # 项目文档
├── sampleinvoice/          # 样本发票（测试用）
├── client/                 # 前端项目 (React)
│   ├── src/
│   ├── public/
│   ├── package.json
│   └── vite.config.ts
├── server/                 # 后端项目 (Express)
│   ├── src/
│   ├── uploads/
│   ├── package.json
│   └── tsconfig.json
├── .gitignore
├── README.md
└── package.json            # 根级 (monorepo workspace)
```
